# Python Learning Projects

This repository contains a series of Python programs developed during my coursework in CIT‑144 and CIT‑120.  
Each script focuses on a specific programming concept and is written in a clear, beginner‑friendly style.

## Included Programs
- **Admissions Program** — Uses decision structures to determine acceptance status.
- **Grid Processor** — Demonstrates nested `while` loops and formatted output.
- **Cube Calculator** — Includes input validation and looping for repeated use.
- **Practice Scripts** — Additional exercises exploring variables, functions, and basic logic.

## Goals
- Strengthen understanding of Python fundamentals.
- Practice writing clean, readable code.
- Build confidence through hands‑on assignments.

## AI Collaboration
Some code segments were drafted or refined with AI assistance.  
I used AI as a learning tool to understand structure, logic, and best practices, but all programs were tested and finalized by me.

## Running the Programs
Make sure Python 3 is installed, then run any script
