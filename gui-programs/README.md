This program is a Tkinter GUI application that calculates important measurements for a right‑circular cylindrical tank. The user enters the tank’s height and radius, and the program instantly computes:

Total volume in cubic feet

Total volume in gallons

Weight of the water in pounds

Top surface area

Outside surface area

Total paintable surface area

The program checks that the user enters positive numeric values, and if the input is invalid, it shows an error message. All results are displayed neatly inside the window.
